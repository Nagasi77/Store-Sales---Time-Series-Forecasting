# Store-Sales---Time-Series-Forecasting
[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://drive.google.com/file/d/1z0MO4Wsq-So6WwrSKH8lbzMVKQpItvl0/view?usp=sharing)
Judul Proyek: Store Sales Time Series Forecasting

Deskripsi
Proyek ini bertujuan untuk memprediksi angka penjualan barang di toko Corporation Favorita yang berlokasi di Ekuador. Saya menggunakan teknik analisis deret waktu untuk melakukan prediksi ini. Hasil prediksi membantu perusahaan dalam mengelola stok barang dengan lebih efisien.

Dataset
Saya menggunakan dataset dari kompetisi Kaggle Store Sales. Data mencakup informasi tentang penjualan harian di berbagai toko. Dataset juga mencakup faktor eksternal seperti harga minyak bumi dan hari libur nasional.

Teknologi yang Digunakan
Bahasa pemrograman Python.
Pustaka Pandas dan NumPy untuk manipulasi data.
Pustaka Matplotlib dan Seaborn untuk visualisasi data.
Pustaka Scikit Learn dan XGBoost untuk pemodelan machine learning.

Langkah Analisis
Pertama. Saya melakukan pembersihan data untuk menangani nilai yang hilang.
Kedua. Saya melakukan analisis data eksploratif untuk menemukan tren dan pola musiman.
Ketiga. Saya melakukan rekayasa fitur dengan menambahkan informasi harga minyak serta kategori hari libur.
Keempat. Saya melatih model regresi untuk memprediksi penjualan masa depan.

Hasil
Model berhasil memberikan prediksi penjualan dengan tingkat kesalahan yang rendah. Saya menggunakan metrik Root Mean Squared Logarithmic Error atau RMSLE untuk mengevaluasi performa model.
